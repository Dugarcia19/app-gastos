# 🚀 DEPLOY RÁPIDO (1 MINUTO)

## ⚡ Opção Mais Fácil: Netlify

1. Vá em [netlify.com/drop](https://app.netlify.com/drop)
2. **Arraste a pasta `app gastos`** inteira
3. ✅ PRONTO! Link gerado automaticamente
4. Seu app está online em segundos

**Vantagem:** 
- Zero configuração
- Link automático
- Deploy contínuo

---

## 2️⃣ Opção GitHub Pages (Recomendada)

1. Crie repositório no GitHub com nome `app-gastos`
2. Faça upload dos arquivos (ou use `git push`)
3. Vá em **Settings → Pages**
4. Escolha branch **main** e **/ (root)**
5. ✅ Link gerado: `https://seu-usuario.github.io/app-gastos/`

**Vantagem:**
- Histórico de versões
- Controle total
- Domínio customizável

👉 **Leia `GITHUB-SETUP.md` para instruções completas!**

---

## 3️⃣ Opção Vercel (Muito Rápida)

1. Vá em [vercel.com](https://vercel.com)
2. Conecte seu GitHub
3. Selecione repositório
4. ✅ Deploy automático

---

## 📱 Acessar no Celular

**Depois que a app estiver online:**

### Android
- Abra no Chrome
- Menu (3 pontos) → "Instalar app"

### iPhone
- Abra no Safari
- Compartilhar → "Adicionar à Tela Inicial"
